# Classroom1

คลังสื่อการเรียนการสอน — รวมทุกวิชาไว้ใน repo เดียว แต่ละวิชาเป็นหน้าเว็บ HTML เดียวจบ
ไม่ต้อง build ไม่ต้องติดตั้ง dependency เปิดไฟล์ในเบราว์เซอร์ได้เลย

## โครงสร้าง

```
Classroom1/
├── index.html          หน้ารวมทุกวิชา — เริ่มที่นี่
├── adv-acctg-1/        การบัญชีขั้นสูง 1 (2601-421)   ✅ พร้อมใช้งาน
├── audit/              การสอบบัญชี                    ✅ พร้อมใช้งาน
├── erp/                ERP                            ✅ พร้อมใช้งาน
├── marketing/          การตลาด                        🚧 กำลังจัดทำ
├── oral-eng/           ภาษาอังกฤษเพื่อการสื่อสาร       🚧 กำลังจัดทำ
└── chat-worker/        ผู้ช่วยตอบคำถาม (Cloudflare Worker)
```

## ผู้ช่วยตอบคำถาม

แต่ละหน้าวิชามีปุ่มแชทให้นิสิตถามคำถามกับผู้ช่วย AI ได้ โดยผู้ช่วยรู้ขอบเขตเนื้อหาของวิชานั้น
เลือกได้ว่าจะใช้ Gemini (ค่าเริ่มต้น) หรือ Claude ที่ `PROVIDER` ใน `chat-worker/wrangler.toml`
**ปุ่มจะยังไม่ปรากฏจนกว่าจะ deploy backend และใส่ URL ลงในหน้าเว็บ** — ดูขั้นตอนทั้งหมดที่
[`chat-worker/README.md`](chat-worker/README.md)

ต้องมี backend ตัวกลางเพราะ GitHub Pages เป็น static hosting ล้วน
ถ้าใส่ API key ลงใน HTML ตรง ๆ ใครกดดู source ก็เอาคีย์ไปใช้ได้

## วิธีเปิด

**เปิดตรง ๆ** — ดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ได้เลย

**Live Server (VS Code)** — ลง extension *Live Server* แล้วคลิกขวาที่ `index.html` → Open with Live Server

**Python** — `py -m http.server 8000` (Windows) หรือ `python3 -m http.server 8000` แล้วเปิด `http://localhost:8000`

## เนื้อหาที่มีแล้ว

### การบัญชีขั้นสูง 1 · 2601-421 (`adv-acctg-1/`)

**บทที่ 1 · การบัญชีสำนักงานใหญ่และสาขา**
บัญชีระหว่างกัน · รายการค้าตัวอย่างตลอดปี · อุปกรณ์ 4 กรณี (เลือกดูได้) · การเก็บหนี้ข้ามหน่วยงาน ·
งบทดลองและงบกำไรขาดทุน · รายการปิดบัญชี · กระดาษทำการงบการเงินรวม ·
ราคาสินค้าที่ส่งไปสาขาพร้อมเครื่องแปลงอัตรากำไรส่วนเพิ่ม · การกระทบยอดเมื่อยอดไม่ตรงกัน · ค่าขนส่งระหว่างสาขา

**บทที่ 2 · การรวมธุรกิจ (TFRS 3)**
รูปแบบการรวม 4 แบบ · สัดส่วนหุ้นกับมาตรฐานที่ใช้ · พัฒนาการของมาตรฐาน · นิยาม "ธุรกิจ" และการทดสอบการกระจุกตัว ·
วิธีซื้อ 4 ขั้นตอน · การรับรู้และวัดมูลค่าพร้อมข้อยกเว้น · ค่าความนิยมและ PPA พร้อมเครื่องคำนวณ ·
ตัวอย่าง A ซื้อ B รวมกรณี DTL · ต้นทุนที่เกี่ยวข้องกับการซื้อ · สินทรัพย์ไม่มีตัวตนที่ระบุได้ ·
การประเมินค่าความนิยมจากกำไรเกินปกติ · กำไรจากการต่อรองราคาซื้อ · ระยะเวลาวัดมูลค่า · BCUCC · เปรียบเทียบ US GAAP

**บทที่ 3 · การทำงบการเงินรวม ณ วันซื้อหุ้น**
ความสัมพันธ์บริษัทใหญ่–บริษัทย่อย · การควบคุมตาม TFRS 10 พร้อมกรณีศึกษาจริงที่ควบคุมได้ทั้งที่ถือหุ้นไม่ถึงครึ่ง ·
ข้อยกเว้นการจัดทำงบรวม · การซื้อธุรกิจแบบย้อนกลับ · การบันทึกบัญชีเมื่อซื้อหุ้น ·
กระดาษทำการ 6 กรณี ตั้งแต่ซื้อที่มูลค่าตามบัญชี จ่ายสูงกว่า จ่ายต่ำกว่า จนถึงซื้อบางส่วนพร้อม NCI สองวิธีวัดมูลค่า ·
สำรองตามกฎหมาย · ทฤษฎีความเป็นหน่วยงานเทียบทฤษฎีความเป็นเจ้าของ · สินทรัพย์ถาวรที่มีค่าเสื่อมราคาสะสม

**บทที่ 4 · การจัดทำงบการเงินรวมภายหลังวันซื้อหุ้น**
งบเฉพาะกิจการเทียบงบรวม · สามทางเลือกบันทึกเงินลงทุน (ราคาทุน 2550+ · TFRS 9 2563+ · ส่วนได้เสีย 2560+) ·
วิธีราคาทุนและ TFRS 9 ทั้ง FVTPL และ FVOCI · วิธีส่วนได้เสียครบทั้ง 4 รายการบันทึกบัญชี ·
กฎ “กำไรตามวิธีส่วนได้เสีย = กำไรส่วนของบริษัทใหญ่ในงบรวม” พร้อม**พิสูจน์จากงบจริง 3 บริษัท** (PTG ใช้ราคาทุนจึงไม่ตรง · แลนด์แอนด์เฮ้าส์และ AIS ใช้ส่วนได้เสียจึงตรงเป๊ะ) ·
ตัวอย่างเดินยาว 3 ปีพร้อมตารางไล่ยอด NCI และเงินลงทุน · **เครื่องไล่ยอดเงินลงทุนแบบกรอกตัวเลขเอง** ·
ปี 25X3 เป็นแบบฝึกหัดพร้อมเฉลย · เปรียบเทียบ Cost เทียบ Equity ·
บริษัทร่วมตาม TAS 28 · อิทธิพลอย่างมีนัยสำคัญ · การนำเสนองบการเงิน · การเลิกใช้วิธีส่วนได้เสีย

**แบบทดสอบ** 34 ข้อ ครอบคลุมทั้งสี่บท พร้อมเฉลยและคำอธิบายทันทีที่เลือกคำตอบ โดยสลับลำดับตัวเลือกทุกครั้ง

**แผนภาพจากสไลด์ต้นฉบับ** 30 ภาพ ฝังไว้ในหน้าโดยตรง ได้แก่ ผังบัญชีสำนักงานใหญ่และสาขา ·
งบกำไรขาดทุนรูปแบบบัญชี · แบบฟอร์มกระดาษทำการเปล่า · การกระทบยอดด้วย Excel Conditional Formatting ·
กรณีศึกษาจริงของ Asset World (การทดสอบการกระจุกตัว 97.86%) · อินโดรามา เวนเจอร์ส (กำไรจากการต่อรองราคาซื้อ) ·
PTT Chemical (งบเสมือนรวมบริษัท) และตาราง PVA · พร้อมงบการเงินจริงของเดลต้า อีเลคโทรนิคส์ PTG แลนด์แอนด์เฮ้าส์ และ AIS ในบทที่ 4

### การสอบบัญชี (`audit/`)

**บทที่ 1 · การสอบบัญชีและข้อกำหนดของผู้บริหาร**
ความเสี่ยงทางธุรกิจกับความเสี่ยงของข้อมูล · นิยามการสอบบัญชี · ภาพรวมกระบวนการ ·
ข้อกำหนดของผู้บริหารตาม PCAOB 5 ข้อ · ข้อกำหนดตาม ASB ทั้งกลุ่มรายการค้าและกลุ่มยอดคงเหลือ ·
ตารางเทียบ PCAOB ↔ ASB แบบกดกรองได้ · การสังเกตและสงสัยเยี่ยงผู้ประกอบวิชาชีพ ·
โครงสร้างสำนักงานสอบบัญชี · เส้นทางสู่วิชาชีพ

**แบบทดสอบ** 12 ข้อ เน้นการระบุข้อกำหนดจากสถานการณ์จริง

**แผนภาพจากสไลด์ต้นฉบับ** 3 ภาพ คือนิยามการสอบบัญชี · Exhibit 1.3 · ผังองค์กรสำนักงานสอบบัญชี

### ERP · ระบบวางแผนทรัพยากรองค์กร (`erp/`)

**บทที่ 1 · ERP และ SAP**
ตลาด ERP และผู้เล่นหลัก · องค์กรยุคก่อน ERP ที่แยกตามหน้าที่และปัญหา interface กับการกระทบยอด ·

วิวัฒนาการ R/1 → R/2 → R/3 · สถาปัตยกรรม 3 ชั้น · โมดูลทั้งหมดพร้อมตัวย่อ (FI CO MM SD PP QM PM PS HR BC ABAP) ·
แนวคิด Best Practice · Industry Solution และเรื่อง Add-On · Business One เทียบ ByDesign · แพลตฟอร์มฮาร์ดแวร์

**บทที่ 2 · การใช้งาน SAP**
SAP GUI กับ SAP Logon · 4 ช่องในหน้าเข้าสู่ระบบและความหมายของ Client · SAP Easy Access ·

Favorites · ธีม · SBWP · SPRO

**บทที่ 3 · การนำระบบมาใช้**
วิธี ASAP แบบน้ำตก · 5 เฟสพร้อมกิจกรรมของแต่ละเฟส · คนในโครงการสาย Technical กับ Functional ·
