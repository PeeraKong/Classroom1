## จดโน้ตและกระดาษทด

ทุกหน้าวิชามีระบบจดโน้ตในตัว ใช้ได้ทันทีไม่ต้องตั้งค่าอะไร

- **ปุ่ม “+ โน้ต” ที่หัวข้อทุกหัวข้อ** — เปิดกล่องที่มีสองแท็บคือ **พิมพ์** กับ **เขียน**
  ใช้พร้อมกันในหัวข้อเดียวได้ บันทึกให้อัตโนมัติ · หัวข้อที่มีอะไรอยู่แล้วปุ่มจะเป็น “โน้ต ✓”
  และกล่องจะเปิดค้างไว้ให้เมื่อกลับมาเปิดหน้าใหม่
- **เขียนด้วยลายมือ** — ใช้ปากกา (Apple Pencil / stylus) นิ้ว หรือเมาส์ก็ได้
  มีปากกา 4 สี · 3 ความหนา · ยางลบ · ย้อนกลับ · ล้าง · บันทึกเป็นรูป PNG
  เส้นหนาบางตามแรงกดของปากกา และ**กันฝ่ามือให้เอง** เมื่อตรวจพบว่ากำลังใช้ปากกา
- **กระดาษทด** — ปุ่มลอยมุมล่างซ้าย มีสามแท็บ
  **พิมพ์ทด** คิดเลขให้ทีละบรรทัดพร้อมผลรวม · **เขียน** แผ่นใหญ่สำหรับทดด้วยลายมือ ·
  **โน้ตทั้งหมด** รวมทุกหัวข้อไว้ที่เดียว กดชื่อหัวข้อเพื่อกระโดดไปหา
  (สลับแท็บบทให้เองถ้าหัวข้อนั้นอยู่คนละบท)
- **คัดลอกทั้งหมด · ดาวน์โหลด .txt · พิมพ์พร้อมโน้ต · ล้างทั้งหมด**

กระดาษทดคิดเลขให้โดยไม่ต้องพิมพ์เฉพาะตัวเลข พิมพ์คำอธิบายไทยปนได้

```
60% * 100,000                    →     60,000
ค่าตัดจำหน่าย 80,000 / 10 ปี      →      8,000
(500,000 + 80,000) * 40%         →    232,000
```

บรรทัดที่ขึ้นต้นด้วย `+` หรือ `-` ใช้ไล่ยอดแบบคอลัมน์บัญชีได้ แล้วดูผลรวมท้ายรายการ

```
+ ส่วนแบ่งกำไร 60% * 50,000       →     30,000
- ตัดจำหน่าย 60% * 8,000          →     -4,800
- ปันผล 60% * 40,000              →    -24,000
ผลรวมทุกบรรทัด                    →      1,200
```

ลายมือเก็บเป็น**เส้น (vector)** ไม่ใช่รูปภาพ ไฟล์จึงเล็กกว่ามากและวาดกลับมาคมชัดทุกความละเอียดหน้าจอ
พื้นกระดาษเป็นสีอ่อนเสมอทั้งธีมสว่างและมืด เพราะหมึกเป็นสีเข้มตายตัว —
ถ้าให้พื้นเปลี่ยนตามธีม ลายมือที่เขียนตอนธีมหนึ่งจะมองไม่เห็นในอีกธีมหนึ่ง

> โน้ตและลายมือเก็บไว้ใน localStorage ของเบราว์เซอร์เครื่องนั้น **ไม่ได้ส่งออกไปที่ไหนทั้งสิ้น**
> จึงไม่ตามไปเครื่องอื่น และจะหายถ้าล้างข้อมูลเว็บไซต์
>
> **ลายมือกินพื้นที่เก็บมากกว่าตัวอักษรมาก** ถ้าเขียนไว้เยอะจนเต็มโควตา ระบบจะเตือน
> ให้กด “บันทึกรูป” เก็บไฟล์ PNG ไว้ก่อนแล้วค่อยล้างของเก่า ·
> ไฟล์ .txt ที่ดาวน์โหลดจะมีเฉพาะข้อความ **ลายมือไม่ติดไปด้วย** ต้องบันทึกเป็นรูปแยก
>
> แม่แบบของส่วนนี้อยู่ที่ `notes.template.html`
> ถ้าเพิ่มวิชาใหม่ให้คัดลอกไปแปะท้าย `index.html` ของวิชานั้น

## ฟังสรุปบท

ทุกหน้าวิชามีเครื่องเล่นเสียงบรรยายในตัว กดปุ่ม **ฟังสรุปบท** ที่มุมซ้ายล่าง

บทบรรยายเขียนไว้ล่วงหน้าครบทุกบท รวม **25 บท 196 หัวข้อ 1,604 ย่อหน้า ประมาณ 255 นาที**
เขียนด้วยสำนวน **อาจารย์กำลังสรุปให้นิสิตฟังในห้อง** มีคำถามชวนคิด ตัวอย่างเทียบเคียง
และคำเตือนว่าตรงไหนคนพลาดบ่อย ไม่ใช่การอ่านข้อความบนหน้าเว็บซ้ำ

| ทำอะไรได้ | รายละเอียด |
|---|---|
| เล่น หยุด ข้าม | ข้ามทีละย่อหน้า หรือกดที่ย่อหน้าใดก็ได้เพื่อเริ่มตรงนั้น |
| ปรับความเร็ว | 0.8× ถึง 1.5× |
| ปรับระดับเสียง | ทุ้ม · ปกติ · สูง |
| เลือกเสียง | แสดงเฉพาะเสียงไทยที่มีในเครื่อง พร้อมป้ายบอก **ชาย/หญิง** และ **ธรรมชาติ** |
| เลื่อนหน้าตาม | หน้าเว็บเลื่อนไปยังหัวข้อที่กำลังอ่านให้อัตโนมัติ |
| ย่อขยาย | กดลูกศรบนหัวหน้าต่างเพื่อย่อเหลือแค่แถบควบคุม สูงราว 150px จะได้ไม่บังเนื้อหาตอนอ่านไปฟังไป กดอีกครั้งเพื่อขยายคืน |

| จำตำแหน่ง | ปิดแล้วเปิดใหม่ได้ที่เดิม แยกตามบท รวมถึงจำว่าย่อไว้และสูงเท่าไหร่ |
| ดาวน์โหลดบทบรรยาย | ได้ไฟล์ `.txt` เอาไปเข้าโปรแกรมทำเสียงอื่นได้ |

### แก้บทบรรยายเป็นชุด

บทบรรยายฝังอยู่ในบล็อก `id="cn-data"` ซึ่งเป็น JSON บรรทัดเดียวยาวหลายหมื่นตัวอักษร
แก้ด้วยมือแล้วพังง่าย จึงมี `tools/patch-narration.py` ที่รับชุดแก้จากไฟล์ข้อมูลแยก
แล้ววางทับเฉพาะหัวข้อที่ระบุไว้

```bash
python3 tools/patch-narration.py audit tools/audit-narration-1.py --check
```

ไฟล์ชุดแก้มีแค่ตัวแปร `PATCH` ซึ่งคีย์คือ `(รหัสบท, ลำดับหัวข้อ)` และค่าคือรายการย่อหน้าชุดใหม่
สคริปต์จะตรวจก่อนแตะข้อมูลว่าทุกคีย์ชี้ไปยังหัวข้อที่มีอยู่จริง แล้วรายงานว่าแต่ละหัวข้อ
ย่อหน้าและจำนวนตัวอักษรเปลี่ยนไปเท่าไร · `--check` คือดูผลอย่างเดียวโดยไม่เขียนไฟล์

พอบทเปลี่ยน **ลายเซ็นก็เปลี่ยน** ไฟล์เสียงเดิมจึงถูกสั่งสร้างใหม่ให้เองตอนรัน `make-audio.py`
และระหว่างที่ยังไม่ได้สร้าง หน้าเว็บจะรู้เองว่า cue ของไฟล์เสียงเดิมไม่ตรงกับจำนวนย่อหน้าของบทรุ่นใหม่
แล้วถอยไปใช้เสียงสังเคราะห์ของเบราว์เซอร์แทน ไม่ทำให้เครื่องเล่นพัง

### อ่านคำภาษาอังกฤษด้วยเสียงอังกฤษ

เสียงไทยล้วนอ่านคำอังกฤษด้วยระบบเสียงไทย ศัพท์อย่าง *compound noun* หรือ *future perfect*
จึงฟังไม่ออก ตัวสร้างเสียงจึง**แยกช่วงภาษาในแต่ละย่อหน้า** แล้วอ่านคนละเสียงก่อนต่อเป็นย่อหน้าเดียว

```
th:ทางเลือกตาม | en:TFRS | th:9 ทั้ง | en:FVTPL | th:และ | en:FVOCI
```

กฎที่ใช้ตัดสินอยู่ใน `tools/langsplit.py`

| กรณี | ผล |
|---|---|
| ตัวเลขที่มีไทยอยู่ข้าง ๆ | ไปกับไทย → *NCI 35,000 หัก* อ่านจำนวนเป็นไทย |
| ตัวเลขในประโยคอังกฤษล้วน | อยู่กับอังกฤษ → *By 2050, businessmen will be…* |
| ช่วงอังกฤษสั้นเกินไป | ยุบกลับเข้าไทย ไม่ให้สลับเสียงถี่จนฟังขาด |
| ตัวย่อตัวพิมพ์ใหญ่ | อ่านเป็นอังกฤษเสมอ แม้จะสั้น |

เลือกเสียงอังกฤษได้ด้วย `--en-voice` หรือช่องเลือกตอนกด Run workflow

| ชื่อย่อ | เสียงจริง |
|---|---|
| `us-male` | en-US-AndrewNeural *(ค่าตั้งต้น)* |
| `us-male2` | en-US-GuyNeural |
| `uk-male` | en-GB-RyanNeural |
| `us-female` | en-US-AvaNeural |
| `uk-female` | en-GB-SoniaNeural |
| `off` | ให้เสียงไทยอ่านทั้งหมดแบบเดิม |

> อยากลองฟังเทียบก่อนสร้างจริง ให้กด Run workflow แล้วเลือก **task = sample**
> จะได้คลิปสั้น ๆ ใน `samples/` พร้อมหน้า `samples/index.html` ไว้กดฟังเทียบกัน
> โดยไม่แตะไฟล์เสียงจริงเลย

### วิธีที่ง่ายที่สุด — ให้ GitHub สร้างให้ ไม่ต้องใช้เครื่องตัวเอง

ไม่ต้องมี Python ไม่ต้องเปิด Terminal ไม่ต้องรอเครื่องตัวเองทำงาน

1. เปิด repo บน **github.com** แล้วไปแท็บ **Actions**
2. เลือก workflow ชื่อ **สร้างไฟล์เสียงบรรยาย** ที่แถบซ้าย
3. กดปุ่ม **Run workflow** ด้านขวา → เลือกสาขา `claude/educational-media-c9pinv` → กด **Run workflow** สีเขียว
4. รอราว 12 นาที เครื่องของ GitHub จะสร้างไฟล์เสียง **แล้ว commit กลับเข้าสาขาให้เอง**
5. กลับมาที่เครื่องตัวเองแล้ว `git pull` ก็ได้ไฟล์เสียงครบ

> **ทำไมต้องมีไฟล์ workflow อยู่บน `main` ด้วย**
> GitHub ลงทะเบียน `workflow_dispatch` **เฉพาะไฟล์ที่อยู่บน default branch** เท่านั้น
> ถ้า `make-audio.yml` อยู่แค่บนสาขาที่พัฒนาอยู่ **ปุ่ม Run workflow จะไม่โผล่เลย**
> จึงมี `.github/workflows/make-audio.yml` วางไว้บน `main` ด้วยอีกชุดหนึ่ง —
> บน `main` มีแค่ไฟล์นี้กับ `README.md` ไม่มีเนื้อหาวิชาใด ๆ
> ตอนกดรันเลือกสาขาไหนก็ได้ ตัว workflow จะทำงานกับสาขานั้น

ใส่ตัวเลือกได้ตอนกดรัน · **วิชา** เว้นว่างคือทุกวิชา หรือพิมพ์ `audit` เฉพาะวิชาเดียว ·
**เสียง** เลือก male หรือ female · **สร้างใหม่ทั้งหมด** สำหรับตอนเปลี่ยนเสียงทั้งชุด

workflow อยู่ที่ `.github/workflows/make-audio.yml` ตั้งให้**กดรันเองเท่านั้น**
ไม่รันอัตโนมัติตอน push เพราะใช้เวลาหลายนาทีและไม่จำเป็นต้องทำทุกครั้งที่แก้โค้ด

> ถ้าแท็บ Actions ขึ้นว่าปิดอยู่ ให้เปิดที่ **Settings → Actions → General → Allow all actions**
> และตรวจว่า **Workflow permissions** ตั้งเป็น **Read and write permissions** เพื่อให้ commit กลับได้

### เสียงผู้ชายทันที โดยไม่ต้องสร้างไฟล์ — เปิดด้วย Microsoft Edge

ถ้ายังไม่อยากสร้างไฟล์ แต่อยากได้เสียงผู้ชายเดี๋ยวนี้ **ให้เปิดหน้าเว็บด้วย Microsoft Edge**

Edge มีเสียงออนไลน์ของตัวเองซึ่งรวม **Niwat** เสียงไทยผู้ชายแบบ neural อยู่ด้วย
และเครื่องเล่นจะ**เลือกให้อัตโนมัติ** เพราะให้คะแนนเสียงชายและเสียงแบบ neural ก่อนเสมอ
ข้อแลกเปลี่ยนคือต้องต่ออินเทอร์เน็ตตลอดเวลาที่ฟัง และใช้ได้เฉพาะใน Edge เท่านั้น

### เสียงผู้ชาย — สร้างไฟล์เสียงจริงบนเครื่องตัวเอง

macOS ไม่มีเสียงไทยผู้ชายมาให้ และเสียงออนไลน์ของ Edge ก็ไม่โผล่ในทุกเครื่อง
วิธีที่ได้ผลแน่นอนคือ **สร้างไฟล์ mp3 ไว้ล่วงหน้า** ด้วยเสียง **Niwat** ซึ่งเป็นเสียงไทยผู้ชายแบบ neural

**วิธีที่ง่ายที่สุด ไม่ต้องแตะ Terminal เลย** — เปิดโฟลเดอร์โปรเจกต์ใน Finder แล้ว
**ดับเบิลคลิกไฟล์ `สร้างไฟล์เสียง.command`** ไฟล์นี้จะย้ายไปโฟลเดอร์ที่ถูกต้องให้เอง
หา Python ในเครื่องให้เอง ติดตั้ง `edge-tts` ให้ Python ตัวเดียวกันนั้นให้เอง แล้วสร้างไฟล์เสียงต่อทันที
เสร็จแล้วหน้าต่างจะค้างไว้ให้อ่านผลก่อน กด Enter จึงปิด

> ครั้งแรก macOS อาจเตือนว่าเปิดไฟล์จากผู้พัฒนาที่ไม่รู้จักไม่ได้
> ให้**คลิกขวา**ที่ไฟล์ เลือก **Open** แล้วกด **Open** ซ้ำอีกครั้งในกล่องที่ขึ้นมา ครั้งต่อไปดับเบิลคลิกได้ปกติ

ถ้าถนัด Terminal มากกว่า ก็รันเองได้

```bash
cd ~/Documents/Classroom1        # ต้องอยู่ในโฟลเดอร์โปรเจกต์ ไม่งั้นจะขึ้น No such file or directory
pip3 install edge-tts
python3 tools/make-audio.py
```

ใช้บริการอ่านออกเสียงตัวเดียวกับปุ่ม Read Aloud ของ Microsoft Edge **ไม่ต้องมี API key
ไม่มีค่าใช้จ่าย** ต้องต่ออินเทอร์เน็ตเฉพาะตอนสร้าง ใช้เวลาราว 25 ถึง 40 นาทีสำหรับทั้ง 25 บท

สคริปต์จะสร้าง `<วิชา>/audio/<บท>.mp3` แล้ว**เขียนตารางเวลาของแต่ละย่อหน้ากลับเข้าไปใน
`index.html`** ให้เอง เครื่องเล่นจึงยังไฮไลต์ตามและกดข้ามย่อหน้าได้เหมือนเดิม

ตัวเลือกเพิ่มเติมใส่ต่อท้ายคำสั่งได้ ถ้าใช้ไฟล์ `.command` ก็ลากไฟล์นั้นมาวางใน Terminal
แล้วพิมพ์ตัวเลือกต่อท้ายได้เหมือนกัน

> สคริปต์จะบอกให้เองว่าพิมพ์ตกอะไรไป

### เปิดเว็บให้ไฟล์เสียงเล่นได้ — ดับเบิลคลิก `เปิดเว็บ.command`

ถ้าเปิดหน้าเว็บด้วยการดับเบิลคลิก `index.html` ตรง ๆ เบราว์เซอร์จะเปิดแบบ `file://`
ซึ่ง **Safari ห้ามหน้าเว็บโหลดไฟล์เสียงข้างเคียง** ผลคือเครื่องเล่นถอยไปใช้เสียงสังเคราะห์
ทั้งที่มีไฟล์ mp3 เสียงผู้ชายอยู่แล้ว

วิธีแก้คือ **ดับเบิลคลิก `เปิดเว็บ.command`** ไฟล์นี้จะเปิดเซิร์ฟเวอร์เล็ก ๆ ในเครื่อง
แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:8765/` ให้เอง ถ้าพอร์ตไม่ว่างจะขยับไปพอร์ตถัดไปเอง
ระหว่างใช้งานอย่าปิดหน้าต่าง Terminal ที่ขึ้นมา ใช้เสร็จกด `Control + C`

เปิดผ่าน `localhost` แล้วได้ครบทุกอย่าง ทั้งไฟล์เสียง รูปภาพ และผู้ช่วยตอบคำถาม

> ถ้าเครื่องเล่นขึ้นกล่องว่า **มีไฟล์เสียงผู้ชายอยู่แล้ว แต่เบราว์เซอร์เปิดไฟล์นี้ไม่ได้**
> พร้อมชื่อไฟล์ นั่นคืออาการนี้เป๊ะ ๆ ให้ใช้ `เปิดเว็บ.command` แทน

**เมื่อมีไฟล์เสียงแล้ว** เครื่องเล่นจะใช้ไฟล์นั้นอัตโนมัติ ไม่ต้องต่อเน็ต
ปุ่มเลือกเสียงกับปุ่มระดับเสียงจะถูกปิด เพราะเสียงถูกอัดไว้แล้ว ส่วนปุ่มความเร็วยังใช้ได้ปกติ
**ถ้ายังไม่ได้สร้าง** หรือหาไฟล์ไม่เจอ เครื่องเล่นจะถอยไปใช้เสียงสังเคราะห์ของเบราว์เซอร์ให้เอง

> ไฟล์ mp3 ทั้งหมดรวมกันราว 15 ถึง 20 MB อย่าลืม `git add` แล้ว commit ด้วย
> และเนื่องจากเป็นไฟล์ mp3 ธรรมดา จะก๊อปไปฟังในโทรศัพท์หรือรถก็ได้

> **ถ้ายังไม่สร้างไฟล์เสียง** เครื่องเล่นจะใช้เสียงสังเคราะห์ของเบราว์เซอร์
> ซึ่งบน macOS มีแต่เสียงผู้หญิง Kanya และมีการเว้นจังหวะระหว่างย่อหน้าให้ฟังเป็นธรรมชาติขึ้น
> บน macOS ติดตั้งเสียงไทยได้ที่ **System Settings → Accessibility → Spoken Content → System Voice → Manage Voices**
>
> แม่แบบของเครื่องเล่นอยู่ที่ `audio.template.html` ส่วนบทบรรยายอยู่ในบล็อก
> `<script type="application/json" id="cn-data">` ท้ายไฟล์ `index.html` ของแต่ละวิชา
