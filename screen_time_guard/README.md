# ScreenTimeGuard – โปรแกรมจำกัดเวลาเล่นคอมของเด็ก

โปรแกรมเล็ก ๆ สำหรับ Windows 10/11 ที่ฝังไว้ในเครื่อง เปิดเองทุกครั้งที่ล็อกอิน และล็อกหน้าจอเมื่อเด็กเล่นครบเวลา

## ทำอะไรได้บ้าง

- ตั้ง **เวลาเล่นต่อวัน** แยกแต่ละวัน (ค่าเริ่มต้น: จันทร์–พฤหัส 60 นาที, ศุกร์ 90 นาที, เสาร์–อาทิตย์ 180 นาที)
- ตั้ง **ช่วงเวลาที่ใช้เครื่องได้** เช่น 07:00–21:00 (นอกช่วงนี้จะล็อกทันที)
- **นาฬิกานับถอยหลัง** มุมขวาล่างของจอ (ลากย้ายได้)
- **เตือนล่วงหน้า** 10, 5 และ 1 นาทีก่อนหมดเวลา
- หมดเวลาแล้วขึ้น **หน้าจอล็อกเต็มจอ** (คลุมทุกจอ, ปิดด้วย Alt+F4 ไม่ได้)
- เลือกได้ว่าหมดเวลาแล้วจะ ล็อกจออย่างเดียว / ออกจากระบบ / ปิดเครื่อง
- ผู้ปกครองใส่รหัสที่หน้าจอล็อก แล้วกด **+15 / +30 / +60 นาที** หรือ **ไม่จำกัดวันนี้** ได้
- ไม่นับเวลาตอนเครื่อง sleep และ (ถ้าเปิดใช้) ตอนไม่มีใครแตะเครื่อง
- กันการโกงแบบง่าย ๆ: ปิดโปรแกรมทิ้งก็เปิดใหม่เองภายใน 1 นาที, ลบไฟล์ไม่ได้, ย้อนนาฬิกาเครื่องก็ไม่รีเซ็ตเวลา

## วิธีติดตั้ง

1. ติดตั้ง Python จาก <https://www.python.org/downloads/>
   ตอนติดตั้งติ๊ก **Add python.exe to PATH** และเลือก **Customize installation → Install Python for all users**
2. คัดลอกโฟลเดอร์ `screen_time_guard` นี้ไปไว้ในเครื่อง
3. คลิกขวาที่ `install.bat` → **Run as administrator**
4. หน้าตั้งค่าจะขึ้นมา ตั้ง **รหัสผ่านผู้ปกครอง** และเวลาที่อนุญาต แล้วกด **บันทึก**
5. เสร็จแล้ว นาฬิกาจะขึ้นมุมจอ และจะเปิดเองทุกครั้งที่ล็อกอิน

## การใช้งานสำหรับผู้ปกครอง

| ต้องการ | วิธีทำ |
|---|---|
| เปลี่ยนการตั้งค่า / ดูเวลาที่ใช้ไป | **ดับเบิลคลิกที่นาฬิกามุมจอ** → ใส่รหัส |
| ให้เล่นต่อตอนหมดเวลา | ใส่รหัสที่หน้าจอล็อก แล้วกดปุ่มจำนวนนาที |
| รีเซ็ตเวลาวันนี้ | หน้าตั้งค่า → **รีเซ็ตเวลาวันนี้** |
| ปิดโปรแกรมชั่วคราว | หน้าตั้งค่า → **ปิดโปรแกรมชั่วคราว** (จะกลับมาเองใน 1 นาที) |
| ถอนการติดตั้ง | คลิกขวา `uninstall.bat` → **Run as administrator** |

ลืมรหัสผ่าน: ล็อกอินด้วยบัญชีผู้ดูแล รัน `uninstall.bat` แล้ว `install.bat` ใหม่

## ข้อแนะนำเพื่อให้ได้ผลดีที่สุด (สำคัญ)

- **ให้เด็กใช้บัญชี Windows แบบ Standard user** (ไม่ใช่ Administrator) และตั้งรหัสบัญชีผู้ดูแลไว้
  ถ้าเด็กเป็น Administrator จะถอนโปรแกรม/แก้ไฟล์ได้เอง
- โปรแกรมนี้กันการโกงได้ระดับหนึ่ง เด็กที่เก่งคอมมาก ๆ อาจหาทางเลี่ยงได้ (เช่น บูตเข้า Safe Mode)
  ถ้าต้องการระบบที่แน่นหนากว่านี้ ใช้ร่วมกับ Microsoft Family Safety ได้
- ค่า "หยุดนับเมื่อไม่ได้แตะเครื่อง" ตั้งเป็น 0 ไว้เป็นค่าเริ่มต้น เพราะถ้าเปิดไว้ เด็กที่ดูคลิปเฉย ๆ โดยไม่ขยับเมาส์จะไม่ถูกนับเวลา

## ไฟล์ในโฟลเดอร์

- `screen_time_guard.py` – ตัวโปรแกรม (ใช้แค่ Python มาตรฐาน ไม่ต้องลงอะไรเพิ่ม)
- `install.bat` / `install.ps1` – ติดตั้งและตั้งให้เปิดอัตโนมัติ
- `uninstall.bat` / `uninstall.ps1` – ถอนการติดตั้ง

ข้อมูลเก็บที่ `C:\ProgramData\ScreenTimeGuard\` (`config.json` = การตั้งค่า, `usage.json` = เวลาที่ใช้ไปวันนี้)
ลองรันเฉย ๆ โดยไม่ติดตั้ง: `pythonw screen_time_guard.py`
