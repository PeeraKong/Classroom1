# ScreenTimeGuard – โปรแกรมจำกัดเวลาเล่นคอมของลูก

ติดตั้งบนคอมของลูกครั้งเดียว จากนั้น **ตั้งค่าและสั่งงานทุกอย่างจากมือถือผ่าน Telegram** ไม่ต้องไปแตะคอมของลูกอีก
ใช้กับ Windows 10/11 · ไม่ต้องลง Python

## ติดตั้ง (ทำครั้งเดียว ประมาณ 3 นาที)

1. **สร้างบอทบนมือถือ:** ใน Telegram ทักหา **@BotFather** แล้วส่ง `/newbot` ตั้งชื่อบอทตามที่ BotFather ถาม
   จะได้ **token** มา หน้าตาประมาณ `123456789:AAF...` (ส่ง token นี้เข้าคอมของลูกด้วยวิธีไหนก็ได้ เช่น Telegram Desktop หรืออีเมล)
2. **ดาวน์โหลด `ScreenTimeGuard.exe`** จากหน้า [Releases](../../releases/tag/screen-time-guard) ของ repo นี้ลงคอมของลูก
3. **ดับเบิลคลิก** `ScreenTimeGuard.exe` แล้วกด **Yes** ตอน Windows ถามสิทธิ์ (ถ้าลูกใช้บัญชีแบบ Standard user ต้องใส่รหัสบัญชีผู้ดูแล)
   - ถ้าขึ้นหน้าจอสีน้ำเงิน "Windows protected your PC" ให้กด **More info → Run anyway** (ขึ้นเพราะโปรแกรมไม่มีลายเซ็นดิจิทัล)
4. วาง token แล้วกด **ติดตั้ง**
5. เปิดแชตกับบอทที่สร้างบนมือถือ แล้วกด **Start** เสร็จแล้ว

บอทจะส่งข้อความต้อนรับมาให้ จากนั้นคอมของลูกก็จำกัดเวลาเองทุกวัน และเปิดเองทุกครั้งที่เปิดเครื่อง

> ค่าเริ่มต้น: จันทร์–พฤหัส 60 นาที, ศุกร์ 90 นาที, เสาร์–อาทิตย์ 180 นาที, ใช้เครื่องได้ 07:00–21:00 น.
> เปลี่ยนได้จากมือถือด้วยคำสั่งด้านล่าง

## สั่งงานจากมือถือ

กดปุ่มที่บอทขึ้นให้ หรือพิมพ์คำสั่งเองก็ได้

| คำสั่ง | ทำอะไร |
|---|---|
| `/status` | ดูเวลาที่ใช้ไป เวลาที่เหลือ และเครื่องล็อกอยู่หรือเปล่า |
| `/add 30` | ให้เล่นต่ออีก 30 นาที (ใส่กี่นาทีก็ได้) |
| `/lock` | ล็อกเครื่องทันที ล็อกไว้จนกว่าจะสั่ง `/unlock` (ปิดแล้วเปิดเครื่องใหม่ก็ยังล็อกอยู่) |
| `/unlock` | ยกเลิกการล็อกที่สั่งไว้ |
| `/unlimited` | ไม่จำกัดเวลาเฉพาะวันนี้ |
| `/reset` | รีเซ็ตเวลาที่ใช้ไปของวันนี้ |

**ตั้งค่า**

| คำสั่ง | ทำอะไร |
|---|---|
| `/settings` | ดูการตั้งค่าทั้งหมด |
| `/limit all 60` | ทุกวันเล่นได้ 60 นาที |
| `/limit weekday 60` / `/limit weekend 180` | วันจันทร์–ศุกร์ / เสาร์–อาทิตย์ |
| `/limit sat 120` | เฉพาะวัน (`mon tue wed thu fri sat sun`) · 0 = ห้ามเล่น |
| `/hours 07:00 21:00` | ช่วงเวลาที่ใช้เครื่องได้ · `/hours off` = ได้ทั้งวัน |
| `/action lock` | หมดเวลาแล้วจะ `lock` ล็อกจอ, `logoff` ออกจากระบบ, หรือ `shutdown` ปิดเครื่อง |
| `/idle 10` | ไม่นับเวลาถ้าไม่มีใครแตะเครื่องเกิน 10 นาที · `0` = นับตลอด (ค่าเริ่มต้น เพราะถ้าเปิดไว้ ลูกที่นั่งดูคลิปเฉย ๆ จะไม่ถูกนับเวลา) |
| `/password 1234` | ตั้งรหัสสำหรับปลดล็อกที่หน้าจอคอม (บอทลบข้อความที่มีรหัสออกจากแชตให้) |

**บอทจะแจ้งเตือนเมื่อ:** มีคนเข้าใช้คอม, หมดเวลาแล้วเครื่องล็อก (ตอบกลับด้วย `/add 30` ได้เลย), และโปรแกรมถูกปิดแล้วเปิดกลับมาเอง ซึ่งอาจแปลว่ามีคนพยายามปิดโปรแกรม (ถ้ารีสตาร์ทเครื่องเร็ว ๆ อาจเตือนผิดได้)

ผู้ปกครองคนอื่นอยากสั่งงานด้วย: ตั้งรหัสด้วย `/password` ก่อน แล้วที่คอมของลูก ดับเบิลคลิกนาฬิกามุมจอ → ใส่รหัส → **สร้างรหัสจับคู่** แล้วให้อีกคนส่ง `/pair ตัวเลข` ไปที่บอท

## ฝั่งคอมของลูกจะเห็นอะไร

- นาฬิกานับถอยหลังเล็ก ๆ ที่มุมขวาล่าง (ลากย้ายได้)
- ป้ายเตือนก่อนหมดเวลา 10, 5 และ 1 นาที
- พอหมดเวลา จะขึ้นหน้าจอล็อกเต็มทุกจอ ปิดด้วย Alt+F4 ไม่ได้ ถ้าผู้ปกครองอยู่ข้าง ๆ ใส่รหัสจาก `/password` ที่หน้าจอล็อกแล้วกด +15/+30/+60 นาทีได้

## ข้อควรรู้

- **ถ้าลูกใช้บัญชี Windows แบบ Standard user จะได้ผลดีที่สุด** ถ้าลูกใช้บัญชี Administrator จะถอนโปรแกรมเองได้
- ตอนติดตั้งมีช่องให้ติ๊ก **"จำกัดเวลาบัญชีที่เป็น Administrator ด้วย"** (ติ๊กไว้ให้แล้ว) ถ้าพ่อแม่ใช้เครื่องเดียวกันด้วยบัญชีผู้ดูแลแยกต่างหาก ให้เอาติ๊กออก บัญชีพ่อแม่จะได้ไม่โดนจำกัด แต่บัญชีลูกต้องเป็น Standard user
- ถ้าคอมไม่มีเน็ต การจำกัดเวลายังทำงานปกติ แค่สั่งจากมือถือไม่ได้ · คำสั่งที่ส่งตอนคอมปิดอยู่ ถ้าค้างนานเกิน 10 นาทีจะไม่ถูกทำตาม
- เด็กที่เก่งคอมมากอาจหาทางเลี่ยงได้ เช่น บูตเข้า Safe Mode หรือแก้ไฟล์ตั้งค่า ถ้าต้องการระบบที่แน่นหนากว่านี้ ใช้ Microsoft Family Safety ร่วมด้วยได้
- token ของบอทเก็บอยู่ในไฟล์ตั้งค่าบนคอม ถ้าคิดว่ามีคนเห็น ให้ส่ง `/revoke` ที่ @BotFather แล้วติดตั้งใหม่ด้วย token ใหม่
- โปรแกรมแอนติไวรัสบางตัวอาจเตือนไฟล์ .exe ที่สร้างด้วย PyInstaller ถ้าเจอให้กดอนุญาต หรือใช้วิธีรันด้วย Python ด้านล่างแทน

## อัปเดต / ถอนการติดตั้ง

ดับเบิลคลิก `ScreenTimeGuard.exe` ตัวที่ดาวน์โหลดมาอีกครั้ง แล้วกด **ติดตั้ง** (เพื่ออัปเดต โดยการตั้งค่าเดิมยังอยู่) หรือ **ถอนการติดตั้ง**

## สำหรับนักพัฒนา

- `screen_time_guard.py` คือตัวโปรแกรมทั้งหมด ใช้แค่ไลบรารีมาตรฐานของ Python
- รันด้วย Python ได้เลย: `python screen_time_guard.py --install` (หน้าติดตั้ง) หรือ `--run` (เริ่มจำกัดเวลา)
- ไฟล์ .exe สร้างอัตโนมัติด้วย GitHub Actions (`.github/workflows/build-screen-time-guard.yml`) ซึ่งทดสอบการติดตั้งและถอนการติดตั้งบน Windows ก่อน ถ้าเป็น branch `main` จะอัปโหลดไว้ที่หน้า Releases
- ข้อมูลเก็บที่ `C:\ProgramData\ScreenTimeGuard\` (`config.json` = การตั้งค่า, `usage.json` = เวลาที่ใช้ไปวันนี้)
